# Stage C 真实 OA 论文人工检查

## 证据口径

- **自动检查**：由 `tools/analyze_stage_c_realworld.py` 从冻结 PDF、最终
  `PhysicalDocument`、Markdown、图片和 manifest 独立复算。
- **人工视觉观察**：实际打开原 PDF 的渲染页与提取 PNG，并阅读对应
  `article.md` 片段。它不是自动判定，也不代表其他出版商版式。
- **合理推断**：仅用于说明残余风险，不计作通过证据。

这 8 篇是新建的 RW2 corpus，不是已丢失 Phase 1B/2 检查点的恢复。

## 总体人工结论

- 8/8 标题基本且规范化精确正确；3 篇错误/缺失元数据样本得到修复。
- 8/8 无系统性整页正文丢失；真实双栏代表 RW2-003 第 2 页已修复为
  列优先。局部作者上标、页眉页脚和参考文献列顺序仍可能有噪声。
- 97 个原生图片对象全部可追溯且文件有效；多数抽查为有效科研图，但
  RW2-005 明确暴露多面板碎片化。
- 39 个页面标记表格 degraded，0 条伪造 Markdown 表格网格。
- 结论限定于这 8 篇 OA born-digital PDF，不外推为真实出版商全面泛化。
